Foodservice Review Inbox

The review return component of a privately operated foodservice competitor intelligence platform.

What the platform does

The platform collects publicly available product catalogue information published by foodservice suppliers and organises it so that products can be compared and classified consistently. Authorised reviewers receive review workbooks by email and return them with their decisions.

What Foodservice Review Inbox does

Foodservice Review Inbox finds completed review workbooks that reviewers have returned by email to the operator's own dedicated Gmail account. For each returned email, it keeps an exact copy of the original message and its workbook attachment so that the review decisions can be checked against the workbook that was issued.

It uses Google's Gmail API with a single permission, https://www.googleapis.com/auth/gmail.readonly, granted only by that dedicated account. The application searches only for messages with a spreadsheet attachment and retrieves only those messages. It cannot send, modify, label, move or delete email, and it does not request access to any other Google account or service.

Returned decisions are never applied automatically. The operator checks each returned workbook and confirms the reviewer's identity independently before any decision is used.

This application is separate from Foodservice Email Bridge, which sends the review workbooks and cannot read email.

Who it is for

This is a private, internal tool. It is not offered to the public, there is no sign-up, and it is authorised only by the operator's own Gmail account.
