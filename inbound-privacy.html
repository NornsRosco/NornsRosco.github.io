Privacy Policy

Effective 18 November 2026

This policy explains what information Foodservice Review Inbox (“the application”) handles and how. The application is privately operated as part of a foodservice competitor intelligence platform (“the platform”).

Google user data

The application requests one Google OAuth scope: https://www.googleapis.com/auth/gmail.readonly. It is authorised only by the operator's own dedicated Gmail account.

  • What it accesses: the application searches that account for messages with a spreadsheet (.xlsx) attachment. For matching messages only, it retrieves the complete original message, including its headers, text and attachment. Although the permission would technically allow other messages to be read, the application does not retrieve messages that do not match this search.
  • What it is used for: identifying completed product classification review workbooks returned by authorised reviewers, checking them against the workbook that was issued, and keeping an exact copy of each returned message and workbook as an audit record of the review.
  • What it is not used for: the application does not send, modify, label, move, archive or delete any messages, and does not access contacts, calendars or any other Google service. The granted scope does not permit it to change the mailbox.
  • Where it is stored: retrieved messages are stored only on systems operated by the operator, in storage that only the operator and the application's own dedicated processing account can access. Notifications about processing failures contain only a technical reference and an error code, never message content.
  • Access credentials: the OAuth credentials issued by Google are stored privately by the operator, are used only for the access described here, and are not shared with anyone.

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the review process described above. It is not sold, not used for advertising, not used to develop, improve or train artificial intelligence or machine learning models, not read by people except the operator for the purpose of checking a review, and not transferred to third parties.

Information about reviewers

A returned message contains the reviewer's email address and anything the reviewer includes in it. This is kept with the audit record of the review. An email address alone is never treated as proof of who made a decision; the operator confirms the reviewer's identity separately and records that confirmation. Reviewer information is not shared, sold or used for marketing.

This website

This website uses no cookies, analytics, tracking or third-party scripts, and has no forms. It is hosted by GitHub Pages; GitHub may process technical information such as visitor IP addresses to operate and secure its service, as described in the GitHub General Privacy Statement.

Retention and removal

Returned messages and workbooks are kept as the audit record of the review decisions for as long as the platform's review process operates, and are not deleted automatically. Reviewers may ask about or request removal of their information using the contact address below; a request may be limited where the record is needed to show how a review decision was made. The Gmail authorisation can be revoked at any time from the Google Account's third-party access settings, after which the application can no longer read email. Revoking it does not affect the separate Foodservice Email Bridge sending permission.
